# Rahuldev — Rahuldevstack.pro

Personal portfolio website of Rahuldev Muthamsetty.

## Quick Reference

- **Stack:** Vite + React 19 + TypeScript, oxlint
- **Content source:** `src/data/portfolioData.ts`
- **Types:** `src/types/index.ts`
- **Styles:** `src/index.css`, `src/App.css`
- **Components:** `src/components/`

## Commands

- `npm run dev` — start dev server
- `npm run build` — typecheck + production build
- `npm run lint` — oxlint
- `npm run preview` — preview production build
